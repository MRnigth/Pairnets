    Add a computer

    1. Install Pairnets. From pairnets.app/add.
    2. Open Pairnets, type and press “Sign in with your browser”. Or “Continue with Google” or “Continue with email”, if you set those up. Its request appears on this page; you approve it here.

    Remove ?

    It stops syncing right away. Its files stay on it, and nothing on your nest is deleted. To add it back, sign in on it again.

    Forget ?

    It only used the old shared token, so it has no key of its own to remove. This takes it off the list. The old shared token is still on, so it comes back the next time it connects; turn the token off under Security to keep it out.
