Code signing policy

How Pairnets' Windows programs are signed, and who decides what gets signed.

Last updated 19 October 2026

Who signs Pairnets

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Only programs built by Pairnets' own public build (GitHub Actions in github.com/MRnigth/Pairnets) from Pairnets' own source code are signed. Each release is approved by hand before it is signed.

Team roles

  • Committers and reviewers: MRnigth
  • Approvers: MRnigth

Every member of the team uses two-step sign-in for GitHub and SignPath.

Privacy

Pairnets sends your files only to your own server (your nest), through the connection you choose when you sign in. Besides that, it looks for new Pairnets versions on GitHub, which you can turn off in Settings. It sends nothing else to other computers unless you ask it to. The details are in the privacy policy.

pairnets.app only serves these pages. Your Pairnets account lives at sync.pairnets.app, which connects your computers to your nest. Your files are stored only on your nest: they pass through sync.pairnets.app on the way and are never kept there. Only computers you have allowed can get in.
